# Bundled fonts

`Inter-Regular.ttf` and `Inter-Bold.ttf` are the static TrueType files from
the Inter 4.1 release (https://github.com/rsms/inter, `extras/ttf/`),
unmodified. Copyright (c) 2016 The Inter Project Authors. They are licensed
under the SIL Open Font License 1.1; the full text is in `OFL.txt`. The
OFL applies to these font files only, not to the rest of flexui (MIT).
